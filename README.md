# Python Basics для AppSec

Простые примеры на Python для подготовки к переходу в AppSec.

## Файлы

- `calculator.py` — простой калькулятор (функции, аргументы, return).
- `text_processor.py` — обработка текста (строки, списки).
- `http_server.py` — простейший HTTP-сервер (http.server, без Flask).

## Как запустить

```bash
python calculator.py
python text_processor.py
python http_server.py
